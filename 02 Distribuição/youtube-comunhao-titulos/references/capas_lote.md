# Troca de capas em lote (vídeos antigos) — Revista Comunhão

Processo da skill `youtube-comunhao-titulos` para trocar as capas de vídeos já publicados. Os critérios de foto e composição estão no SKILL.md, Passo 12 (12.5 e 12.5.1).

1. Liste os vídeos pela playlist do programa, do mais recente para o mais antigo, e separe **lotes de 10**. Pule duplicados (mesma capa vale para os dois vídeos do mesmo episódio), chamadas/promos e debates sem definição de capa; liste-os à parte para o Mário decidir.
2. Para cada vídeo: quadros (12.5.1), recorte, manchete nova a partir do tema (≤ 60 caracteres e até 3 linhas, regras do 12.1; sem inventar), nome do convidado.
3. Monte uma **grade** com as capas novas e, no canto de cada uma, a capa atual, e **mostre ao Mário antes de trocar**. Troque só depois do "pode trocar" daquele lote.
4. Troque no Studio (`references/studio.md` → "Notas práticas" → "Trocar a miniatura") e confirme pelo botão Salvar desativado. O YouTube pode levar alguns minutos para mostrar a capa nova.
5. Guarde as capas em `G:\Meu Drive\Comunhão shorts\capas_lote\<lote>\`. Nunca exclua nada; Short antigo substituído vai para Privado.
